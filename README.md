## Requerimientos y funciones

| Requerimiento | Función responsable |
|---|---|
| Req. 1 - Registro básico | struct `Solicitud` |
| Req. 2 - Validar código de estudiante | `ValidarCodigoEstudiante` |
| Req. 3 - Validar tipo de consulta | `ValidarTipoConsulta` |
| Req. 4 - Menú sin retorno | `MostrarMenu` |
| Req. 5 - Asignar prioridad | `AsignarPrioridad` |
| Req. 6 - Validar texto obligatorio | `ValidarTextoObligatorio` |
| Req. 7 - Mostrar resumen | `MostrarResumenSolicitud` |
| Req. 8, 9, 10 - Registro múltiple, parámetros y alcance | `RegistrarNuevaSolicitud`, `MostrarTodasLasSolicitudes` |
| Req. 11 - Pruebas de validación | `EjecutarPruebas` |
